## 2. 目标 / 非目标

**若立项的目标（可验证）**
- G1：定义**探索预算**（轮次/token 上限），在**显式探索意图**下允许"试错式"多假设推进；
- G2：≥1 个**真实消费场景**（否则为"为理论可能性加机制"）；
- G3：与既有 `exploration_fatigue` **不冲突**（探索预算耗尽 ⇒ 收敛，而非无限探索）。

**非目标**
- N1：**不**新建 Co-Scientist 式多 Agent 科研框架（远超本仓当前需求）。
- N2：**不**改 `ReActLoop` 的既有终止语义（`exploration_fatigue` 等 14 值不动）。
- N3：**不**加"探索"专用开关（避免与刚建立的默认关开关纪律叠加噪声）。

## 3. 现状判定（为何**暂不实施**）

> 书中 Ch.21 的核心是「**主动生成假设 → 设计实验 → 进化**」的**开放性科研闭环**。本仓是**单机单用户本地代理**（`project_rules.md §1.3`），主要交互是"用户给任务 → 代理执行"，**没有**"自主提出研究假设并验证"的真实场景。

- 强制实现只会得到**无消费者的探索循环** ⇒ 命中 **CS03（回退/投机最小化）** + **R12-1**。
- 现有的 `ExploreAgentStrategy`（提示词级）+ `exploration_fatigue`（防御）**已覆盖本仓真实需要**（"收集信息" + "防绕圈"）。
