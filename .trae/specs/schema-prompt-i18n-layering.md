## §1 背景与判定（2026-10-07）

**已做**：按 §E-1 计划完成 **批次 1–6** —— **45 个源文件 / 223 处**自然语言描述中文化 + **2 个测试文件**断言同批更新（批次 6）。

**同日判定（用户）**：该需求**非当下必须**；若做，应**以 i18n 为基础、结合项目最终形态、分层推进多语言** ⇒ **停止剩余批次 7–10**。

**理由（三条，取证见 §E）**：
1. **层次错位**：工具卡/技能列表的中文展示本应由前端 i18n（`client/src/i18n`）承载；**以改后端 schema 充当 UI 文案**是层次错配（§E 裁定第 4 条已明确此点）。
2. **改了但无法评估**：改 `description` = 改**模型可见 schema**（行为变更）；项目前置约束 1 要求「分批灰度 + 前后对比」，而本机**无灰度通道、6 批均未做前后对比** ⇒ 属"已改、无观测"。
3. **时机**：项目最终形态（是否多语言 / 默认语言 / 展示面归属）未定型；先扫完会把"中文默认"写进模型可见契约，后期走 i18n 分层还需再扫一遍 ⇒ **重复劳动**。

---

## §2 口径（2026-10-07 修订，取代 §E 原口径第 1/3 条）

1. **后端 schema 保持稳定**：新增/修改工具与参数的 `description` **用英文**（不预设展示语言）。
2. **存量不回改**：批次 1–6 的 **223 处中文保留**（自洽、门禁全绿）；其余英文存量亦**不扫改**（终止"全量推进"）。
3. **多语言由 i18n 分层承载**（本专项）：UI 展示语言走 `client/src/i18n`；若确需本地化**模型可见描述**，须在**渲染 tool schema 的单一出口**按 locale 解析（一处、可测、可回滚）。
4. **协议与标识恒英文**：工具名 / 参数名 / 枚举取值 / 文件路径 / 文件名 / JSON 键 / 格式标签（如 `VERDICT:`、`[SYSTEM] `）/ `{{占位符}}` / frontmatter 键 —— 与 §E 第 2 条同。

## §3 前置条件（启动门槛，逐项打勾方可启动）

- [ ] **项目最终形态定型**：多语言支持范围（目标语言集合）、默认语言、是否面向多语言用户
- [ ] **前端 i18n 归属确定**：工具卡 / 技能列表 / 轨迹视图的文案是否统一走 i18n 资源
- [ ] **灰度与观测能力就绪**：具备分批灰度 + 前后对比（前置约束 1 的硬要求；当前**不具备**）

## §4 方案骨架（待细化，**本专项未实施**）

1. **定位单一出口**：确认 tool schema 渲染的唯一出口（候选：`ToolRegistry.getToolSchemas()` → `tool.getInfo()` 一线，与 `ToolDefinitionAdapter`），本地化只在此处发生。
2. **资源表**：`locale × <toolName>[.<param>]` → 描述文案；**缺项回退**到 schema 内置文案（不抛错、不静默空 —— 与既有占位符口径一致）。
3. **分层推进**（由外到内，逐层灰度）：
   - 第 1 层：**仅 UI 展示面**（不改模型可见 schema）—— 收益/风险比最高，优先做；
   - 第 2 层：**模型可见描述**（需 §3 全部就绪 + 前后对比）。
4. **一次一类**：先 skills → 再 tools → 最后内建命令/系统提示词；每类独立灰度与回滚。
5. **不重复**：禁止在 100+ 工具文件里各写一份多语言分支（本次 6 批已证此路不可持续）。

---

## §5 触发条件（何时启动本专项）

① 项目宣布支持多语言（≥2 个目标语言）；或
② 用户明确要求「模型可见描述」本地化；或
③ 前端 i18n 专项启动并覆盖工具卡 / 技能列表文案。

## §7 与既有规则的关系

- **CS01（归一化）**：本专项落地时须复用既有 i18n 基础设施（`client/src/i18n`），不得另起一套。
- **CS03（回退最小化）**：§4.2 的缺项回退是**真实场景**（资源未覆盖新工具）⇒ 允许；禁止"以防万一"式双轨。
- **前置约束 1（行为变更须灰度）**：§3 第 3 项即其硬落点。
- **`versioning.md` / spec 生命周期**：本 spec 在启动实施时进入 reviewing → implemented；**若最终决定不做多语言，须按规范删除本 spec**（不保留过期 spec）。
