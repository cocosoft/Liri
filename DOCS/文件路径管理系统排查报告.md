## 三、发现的问题及修复状态

### ✅ P0：BashTool/GlobTool 默认 cwd = process.cwd()

**文件**：`app/src/tools/BashTool/BashTool.ts:346`、`app/src/tools/GlobTool/GlobTool.ts:24`

**修复方式**：不在每个工具内修改，而是**在入口处全局修复**。

```typescript
// main.ts → main() 第一行
process.chdir(resolveProjectRoot());
```

`process.chdir()` 是 OS 级别的 chdir 系统调用，修改进程当前工作目录。此后所有 97 个文件中 `process.cwd()` 调用自动返回正确的项目根路径。

### ✅ P0：ChatManagerImpl.deleteSession 不同步清理持久化存储

**文件**：`app/src/chat/ChatManager.ts:2505`

**修复内容**：
- `deleteSession()` 新增 `this.sessionGateway.deleteSession(sessionId)` 同步删除
- 新增 `clearAllSessions()` 方法清除所有会话（内存 + 持久化）

### ✅ P0：AI 写文件/下载文件位置约定

**修复方式**：
- `main.ts` 注入 `OUTPUT_DIR` 和 `DOWNLOADS_DIR` 环境变量到所有子进程
- `paths.ts` 新增 `resolveDownloadsDir()` + `DOWNLOADS_DIR` 常量
- 系统提示词中告知 AI 文件路径约定

| 环境变量 | 实际路径 | 用途 |
|----------|---------|------|
| `OUTPUT_DIR` | `~/.pyapp/output/` | AI 生成文件（报告、代码片段等） |
| `DOWNLOADS_DIR` | `~/.pyapp/downloads/` | AI 下载材料（网页、图片、文档等） |

### ✅ P1：LogConfig.ts 硬编码路径

```diff

```

### ✅ P1：AuditFilesystem.ts 硬编码路径

- `data/oauth-tokens.json` → `app/data/oauth-tokens.json`

### ✅ P1：DocumentVersionService.ts 硬编码路径

```diff
+ storageDir: resolveDataSubDir('document_versions'),
```

### ✅ P1：MediaCache.ts 硬编码路径

**文件**：`app/src/channels/cache/MediaCache.ts`

```diff

+ cacheDir: resolveDataSubDir('cache/media'),
```

### ✅ P1：envUtils.ts 重复实现

**文件**：`app/src/utils/envUtils.ts`

`getConfigHomeDir()` 委托给 paths.ts 的 `resolvePyappHome()`，移除硬编码 `join(homedir(), '.pyapp')`。

### ✅ P1：FileSystemUnifiedStorage 路径嵌套

**文件**：`app/src/session/storage/FileSystemUnifiedStorage.ts`

**问题**：路径模式为 `{SESSIONS_DIR}/sessions/{sessionId}/`，导致双重 `sessions/sessions/`。

**修复**：`sessionDir()` 直接使用 `basePath + sessionId`，消除嵌套。

```diff
- return path.join(basePath, 'sessions', sessionId);
+ return path.join(basePath, sessionId);
```

### 🟡 P2：新旧存储层并存

| 实现 | 文件路径 | 状态 |
|------|---------|------|
| `FileSystemStorage`（旧） | `{SESSIONS_DIR}/{sessionId}/session.json` | 路径已统一 ✅ |
| `FileSystemUnifiedStorage`（新） | `{SESSIONS_DIR}/{sessionId}/messages.jsonl` | 路径已统一 ✅ |
| `SessionGateway` 默认使用 | `FileSystemUnifiedStorage` | 生产使用 ✅ |

**说明**：新旧两层存储路径已统一（都指向 `{SESSIONS_DIR}/{sessionId}/`），但代码层仍然存在两个独立的实现。完全重构需要统一 `SessionStore` 和 `SessionFactory` 使用 `SessionGateway`，涉及较大架构改动。

### 🟢 P3：paths.ts 常量模块加载时求值

**风险**：`export const PROJECT_ROOT = resolveProjectRoot()` 在首次导入时确定。

**说明**：实际无害，因为：
1. `process.chdir(resolveProjectRoot())` 在 `main()` 中**在所有模块加载前**执行
2. `setUserDataDirOverride()` 在 init 流程中早于 `ensureDataDirectories()` 调用
3. 常量在模块加载时求值一次，后续运行期间不会变化
