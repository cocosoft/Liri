# 模型管理系统全方位升级方案 v3.0

## 一、用户场景与设计理念

### 1.1 典型用户旅程

```
用户小王打开 Liri 客户端
│
├─ 状态栏右下角看到 [🔴 claude-sonnet-4-6] ← 当前模型一目了然
│
├─ 点击状态栏 → 弹出模型选择面板（不离开当前界面）
│   ├─ 最近使用: claude-sonnet-4-6, gpt-4o, deepseek-chat
│   ├─ 按任务分类:
│   │   ├─ 💬 对话: claude-sonnet-4-6  ← 当前
│   │   ├─ 💻 编程: claude-opus-4-6
│   │   ├─ 🌐 翻译: gpt-4o-mini
│   │   └─ ⚡ 快速: claude-haiku-3-5
│   └─ [管理模型] → 跳转到模型管理页面
│
├─ 首次使用 → 模型管理页面
│   ├─ 看到 8 个快速预设（OpenAI/Anthropic/DeepSeek/Google...）
│   ├─ 点击「Anthropic」→ 自动填入 baseUrl + 模型列表
│   ├─ 填入 API Key → 保存
│   └─ 回到对话界面，状态栏显示模型
│
└─ 高级用户 → 管理页面
    ├─ 创建「按任务分工」规则
    │   对话 → claude-sonnet-4-6
    │   编程 → claude-opus-4-6
    │   翻译 → gpt-4o
    ├─ 添加自定义模型（Ollama 本地）
    │   填 baseUrl → 自动发现模型列表
    └─ 调整模型上下文大小、定价等元数据
```

### 1.2 核心设计原则

| 原则 | 说明 |
|------|------|
| **状态可见** | 当前模型始终在状态栏显示，不迷路 |
| **切换不中断** | 模型选择面板浮层式弹出，不离开对话界面 |
| **任务驱动** | 按使用场景自动匹配模型，而非手动每次选择 |
| **预设优先** | 主流厂商一键配置，自定义仅需补全少数信息 |
| **渐进披露** | 简单用户看到简单界面，高级用户可深入配置所有参数 |

### CORE-2: 按任务分工的模型策略

#### 概念

用户不再是「设置一个模型用到底」，而是告诉系统：

> 「我用 Claude 聊天、GPT-4o 翻译、Opus 写代码、Haiku 做快速问答」

系统自动根据当前对话的上下文/意图选择模型。用户也可以随时手动覆盖。

#### 配置模型

```yaml
# ~/.pyapp/models.yaml
agents:
  defaults:
    models:
      chat: claude-sonnet-4-6       # 日常对话
      coding: claude-opus-4-6        # 编程任务
      translation: gpt-4o            # 翻译
      quick: claude-haiku-3-5        # 快速问答
      embedding: text-embedding-3-small  # 嵌入
```

#### 前端 UI


### CORE-6: 模型健康监测 + 自动降级

#### 概念

如果主力模型不可用（API 超时/余额不足/限流），系统自动切换到备用模型，不影响用户使用。

#### 配置

```yaml
agents:
  defaults:
    model:
      primary: claude-sonnet-4-6
      fallback: gpt-4o              # 主力失败时自动切换
      fallbackMode: auto             # auto | manual
    models:
      chat:
        primary: claude-sonnet-4-6
        fallback: gpt-4o
```

#### 工作流

```
用户发送消息
  → 调用 claude-sonnet-4-6
  → 429 Rate Limit / 超时
  → 自动重试 gpt-4o（用户无感知）
  → 状态栏提示 [⚠ 已降级至 gpt-4o]
  → 用户点击 ⚠ 查看详情
       ├─ 原因: Anthropic API Rate Limited
       ├─ 当前: gpt-4o (备用)
       └─ [恢复主力] 或 [管理降级规则]
```

## 七、用户体验对照表

| 场景 | 当前体验 | 升级后体验 |
|------|---------|-----------|
| 查看当前用什么模型 | 无显示 | 状态栏清楚显示 `⚡ claude-sonnet-4-6` |
| 切换模型 | 离开当前界面去管理页面 | 点击状态栏弹出面板，3 秒切换 |
| 首次使用配置 | 需要理解 Provider/API 等概念 | 点预设按钮 → 填 API Key → 完成 |
| 多模型管理 | 手动每次选择 | 按任务自动分配，智能切换 |
| 自定义模型 | 不支持 | 填 baseUrl → 自动发现，或手动配置全部参数 |
| 模型异常处理 | API 报错中断用户操作 | 自动降级到备用模型，提示但不中断 |
| 了解模型差异 | 无从比较 | 选中两个模型 → 并排对比 |
| 查看使用成本 | 需打开独立 /cost 页面 | 状态栏直接显示 `$0.03` |
