## 系统要求

- **运行时**: Node.js >= 20 或 Bun >= 1.0
- **操作系统**: Windows 10+, macOS 12+, Linux (内核 5.x+)
- **内存**: 最低 512MB，推荐 2GB+
- **磁盘**: 最低 500MB 可用空间

## 快速开始

```bash
# 安装依赖
cd backend
bun install

# 启动应用
bun run dev
```
