### 2 简介

> Liri 是一个基于 TypeScript + Rust 架构的 AI Agent 后端服务。
>
> 它不只是聊天机器人——它能理解你的意图、执行命令、管理任务、调用工具、甚至与其他 AI Agent 协作。
>
> 40+ 模块化子系统,4 阶段分层启动,三级延迟加载策略——强大但不臃肿。

### 3 核心能力(6 张卡片)

| 能力 | 说明 |
|------|------|
| 🤖 **智能对话** | 多模型支持,上下文感知,流式响应 |
| 🛠 **工具调用** | 100+ 内置工具:Bash、Web 搜索、代码编辑、文件操作 |
| 🔒 **安全可控 | AST 级命令分析、细粒度权限、Docker 沙箱 |
| 🌐 **多平台** | 30+ 消息渠道:Discord、Slack、微信、飞书、Telegram...... |
| 🧠 **记忆系统** | 长期记忆、知识库、向量检索 |
| 🔌 **可扩展** | 插件系统、MCP 协议、ACP 多 Agent 通信 |

### 6 快速开始

```bash
# 安装

# 配置
cp .env.example .env
# 填入你的 API Key

# 启动
bun run dev
```
