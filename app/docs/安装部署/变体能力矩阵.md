## 1. 变体总览

| 变体 | 说明 | 最小工具面 | 构建期裁剪 |
|---|---|:--:|---|
| `core` | 核心版 — 最小功能集，仅 CLI + 7 个基础工具 | 是 | DROP_CHANNELS_ALL |
| `personal` | 个人版 — Core + Telegram/Web 通道 + 插件 + 文件转换 | 否 | — |
| `coding` | 编码版 — Personal + LSP + Notebook + 代码分析 | 否 | — |
| `enterprise` | 企业版 — Coding + Slack/Discord + Auth + Audit + Sandbox + Office | 否 | — |
| `headless` | 无界面服务端版 — 与 personal 同能力面，构建期剔除 UI（DROP_UI），通道默认保留 | 否 | DROP_UI |

> 「最小工具面」= 只保留 7 个基础工具（见 `variant-matrix.ts` 的 `core` 注释）。
