# Thinking - 思考工具

## 描述

Thinking 工具允许 Agent 进行深度思考和分析，用于复杂问题的推理。

## 输入参数

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `thought` | string | 是 | 思考内容 |

## 使用示例

```javascript
// Agent 内部使用
Thinking({
  thought: "让我分析这个问题的几个方面..."
})

// 逐步推理
Thinking({
  thought: "第一步，我需要了解需求。第二步，设计方案。"
})
```

## 用途

- 复杂问题推理
- 多步骤分析
- 方案比较和评估
- 错误诊断

## 注意事项

- Thinking 工具仅供 Agent 内部使用
- 用户不会直接看到思考过程
- 思考内容影响 Agent 的后续决策
