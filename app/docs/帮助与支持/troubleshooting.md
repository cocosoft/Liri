# 故障排除

## 启动问题

### 应用无法启动

**可能原因**:
- 端口被占用
- 环境变量未配置
- 依赖未正确安装

**解决方案**:
```bash
# 检查端口占用
netstat -ano | findstr :3000

# 验证环境变量
cat .env

# 重新安装依赖
bun install --force
```

### 启动后立即退出

**可能原因**:
- 配置文件语法错误
- 必需的配置项缺失

**解决方案**:
```bash
# 验证 JSON 配置
bun run validate-config

# 检查必需的配置项
/config show
```

## 运行时问题

### 内存占用过高

**解决方案**:
- 减小缓存大小: `/config set CACHE_MAX_SIZE 50MB`
- 清理过期会话: `/session clean`
- 重启应用

### 响应速度慢

**解决方案**:
- 检查网络延迟
- 减小 model max_tokens
- 切换到更快的模型

## 工具问题

### 文件操作失败

- 确认文件路径在允许范围内
- 检查文件权限
- 查看治理策略配置

### 网络请求失败

- 检查网络连接
- 确认 URL 未在黑名单中
- 检查代理设置

## 获取帮助

如果以上方案无法解决问题，请提交 Issue 或联系技术支持。
