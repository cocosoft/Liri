# 内置插件

Liri 内置了以下插件，开箱即用。

## 插件列表

| 插件 | 说明 | 默认启用 |
|------|------|----------|
| `code-analyzer` | 代码分析工具 | 是 |
| `file-manager` | 文件管理增强 | 是 |
| `git-integration` | Git 集成 | 否 |
| `web-scraper` | 网页抓取增强 | 是 |
| `data-visualizer` | 数据可视化 | 否 |
| `note-taker` | 笔记管理 | 否 |

### code-analyzer

提供代码质量分析和建议：

- 代码复杂度分析
- 潜在 Bug 检测
- 代码风格检查
- 性能建议

### git-integration

Git 版本控制集成：

- 提交管理
- 分支操作
- 差异查看
- 历史查询

### data-visualizer

数据可视化能力：

- 图表生成
- 数据分析
- 报告生成
- 导出支持
