# 插件概述

## 架构

```
┌─────────────────────────────────────┐
│           插件管理器                  │
│  ┌─────┐ ┌─────┐ ┌─────┐           │
│  │插件A │ │插件B │ │插件C │  ...     │
│  └─────┘ └─────┘ └─────┘           │
│         │         │                  │
│         ▼         ▼                  │
│  ┌─────────────────────────────────┐ │
│  │        钩子系统                  │ │
│  └─────────────────────────────────┘ │
└─────────────────────────────────────┘
```

## 插件能力

- **工具注册**: 向系统注册新的工具
- **技能注册**: 添加新的技能模板
- **事件监听**: 响应系统事件
- **钩子注入**: 在系统流程中插入自定义逻辑
- **UI 扩展**: 扩展命令行界面

## 安装插件

```bash
# 从插件市场安装
/plugin install plugin-name

# 从本地路径安装
/plugin install ./my-plugin

# 从 URL 安装
/plugin install https://example.com/plugin.zip
```

## 管理插件

```bash
# 列出已安装插件
/plugin list

# 启用插件
/plugin enable plugin-name

# 禁用插件
/plugin disable plugin-name

# 卸载插件
/plugin uninstall plugin-name
```
