# 插件架构

## 概述

Liri 的插件系统支持通过插件扩展功能，插件可以注册工具、技能和事件处理器。

## 架构

```
┌─────────────────────────────────────────┐
│              插件管理器                   │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐  │
│  │  插件 A  │ │  插件 B  │ │  插件 C  │  │
│  └──────────┘ └──────────┘ └──────────┘  │
│         │            │            │       │
│         ▼            ▼            ▼       │
│  ┌─────────────────────────────────────┐  │
│  │           钩子系统                  │  │
│  └─────────────────────────────────────┘  │
└─────────────────────────────────────────┘
```

## 插件接口

```typescript
interface Plugin {
  meta: PluginMeta;
  onInit(): Promise<void>;
  onEnable(): Promise<void>;
  onDisable(): Promise<void>;
  onUninstall(): Promise<void>;
}
```

## 扩展点

- **工具注册**: 插件可以向系统注册新的工具
- **技能注册**: 插件可以添加新的技能模板
- **事件监听**: 插件可以监听和响应系统事件
- **钩子注入**: 插件可以在系统流程中注入自定义逻辑

## 依赖管理

```json
{
  "dependencies": {
    "py-app": ">=1.0.0",
    "other-plugin": "^2.0.0"
  }
}
```

## 隔离机制

- 每个插件运行在独立的模块作用域
- 插件间通过事件总线通信
- 插件崩溃不影响主进程
