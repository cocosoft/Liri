# Liri 模块管理使用指南

## 🚀 快速开始

### 1. 安装和配置

模块管理系统已经集成到项目中，无需额外安装。确保你的项目依赖是最新的：

```bash
# 安装依赖
bun install

# 验证模块管理系统
bun run modules:check
```

### 2. 基本使用

#### 2.1 初始化模块系统

```typescript
// 方式1: 使用便捷函数
import { initializeModules } from './modules';

await initializeModules();
console.log('模块系统初始化完成');

// 方式2: 使用初始化器
import { moduleInitializer } from './modules';

await moduleInitializer.initializeAllModules();
console.log('模块系统初始化完成');
```

#### 2.2 导入模块

```typescript
// 方式1: 使用别名路径
import { importModule } from './modules';

const agentModule = await importModule('@modules/agent');
const aiModule = await importModule('@modules/ai');

// 方式2: 从注册表导入
import { importFromRegistry } from './modules';

const coreModule = await importFromRegistry('core');
const configModule = await importFromRegistry('config');

// 方式3: 批量导入
import { importManager } from './modules';

const modules = await importManager.importMultiple([
  '@modules/core',
  '@modules/ai',
  '@modules/agent'
]);
```

## 📚 核心概念

### 1. 模块分类

模块按照功能分为8个类别：

```typescript
import { ModuleCategory } from './modules';

// 核心模块
ModuleCategory.CORE        // 核心功能
ModuleCategory.INFRASTRUCTURE // 基础设施

// 功能模块  
ModuleCategory.AI          // AI相关
ModuleCategory.AGENT       // 代理
ModuleCategory.BRIDGE      // 桥接

// 界面模块
ModuleCategory.UI          // 用户界面
ModuleCategory.CLI         // 命令行

// 工具模块
ModuleCategory.TOOLS       // 工具管理
ModuleCategory.COMMANDS    // 命令

// 数据模块
ModuleCategory.MEMORY      // 记忆管理
ModuleCategory.CACHE       // 缓存

// 系统模块
ModuleCategory.SECURITY    // 安全
ModuleCategory.PERFORMANCE // 性能
ModuleCategory.MONITORING  // 监控
```

### 2. 模块生命周期

每个模块都有明确的生命周期：

1. **注册** - 模块定义被添加到注册表
2. **初始化** - 模块依赖解析和初始化
3. **运行** - 模块正常提供服务
4. **销毁** - 模块资源清理

## 🔧 实用示例

### 示例1: 创建新模块

#### 步骤1: 创建模块目录结构

```
src/
└── my-new-module/
    ├── index.ts           # 模块入口
    ├── types/
    │   └── index.ts       # 类型定义
    ├── services/
    │   └── MyService.ts   # 服务实现
    ├── utils/
    │   └── helpers.ts     # 工具函数
    └── README.md          # 模块文档
```

#### 步骤2: 实现模块入口

```typescript
// src/my-new-module/index.ts

/**
 * 我的新模块
 * 提供XXX功能
 */

export * from './types';
export * from './services';
export * from './utils';

export { MyService } from './services/MyService';

export default MyService;
```

#### 步骤3: 注册模块定义

在 `src/modules/ModuleDefinitions.ts` 中添加：

```typescript
'my-new-module': {
  id: 'my-new-module',
  name: 'my-new-module',
  displayName: '我的新模块',
  version: '1.0.0',
  category: ModuleCategory.OTHER,
  description: '提供XXX功能的新模块',
  dependencies: ['core', 'infrastructure'],
  optionalDependencies: []
}
```

### 示例2: 模块间依赖管理

```typescript
import { moduleRegistry } from './modules';

// 检查模块依赖
const dependencies = moduleRegistry.resolveDependencies('agent');
console.log('Agent模块依赖:', dependencies.map(d => d.id));

// 验证依赖关系
import { validateModuleDependencies } from './modules';

const validation = validateModuleDependencies();
if (validation.valid) {
  console.log('依赖关系验证通过');
} else {
  console.error('依赖关系问题:', validation.errors);
}
```

### 示例3: 模块状态监控

```typescript
import { checkModuleInitialization, moduleInitializer } from './modules';

// 检查初始化状态
const { allInitialized, states } = checkModuleInitialization();
console.log('所有模块已初始化:', allInitialized);

// 获取详细状态
for (const [moduleId, state] of Object.entries(states)) {
  console.log(`${moduleId}: ${state.status}`);
}

// 获取统计信息
const stats = moduleRegistry.getStatistics();
console.log('模块统计:', stats);
```

## 📋 最佳实践

### 1. 模块设计原则

#### 单一职责原则
每个模块应该只负责一个明确的功能领域。

```typescript
// ✅ 正确 - 职责明确
'cache': { /* 缓存功能 */ }
'memory': { /* 记忆管理 */ }

// ❌ 错误 - 职责混杂
'cache-and-memory': { /* 缓存和记忆混合 */ }
```

#### 依赖倒置原则
依赖抽象而不是具体实现。

```typescript
// ✅ 正确 - 依赖接口
interface IStorage {
  save(data: any): Promise<void>;
  load(): Promise<any>;
}

// ❌ 错误 - 依赖具体实现
import { FileStorage } from './FileStorage';
```

### 2. 导入规范

#### 使用别名路径
```typescript
// ✅ 正确
import { Agent } from '@modules/agent';
import { AI } from '@modules/ai';

// ❌ 错误
import { Agent } from '../../agent/agent.ts';
```

#### 避免循环依赖
```typescript
// 使用依赖注入解决循环依赖
class ServiceA {
  constructor(private serviceB: ServiceB) {}
}

class ServiceB {
  constructor(private serviceA: ServiceA) {}
}
```

### 3. 错误处理

#### 统一错误类型
```typescript
import { ModuleError } from './modules/errors';

try {
  await module.initialize();
} catch (error) {
  throw new ModuleError(
    `初始化失败: ${error.message}`,
    moduleId,
    'INIT_FAILED'
  );
}
```

#### 优雅降级
```typescript
import { importModule } from './modules';

// 带错误处理的导入
try {
  const module = await importModule('@modules/some-module', {
    errorHandling: 'log'
  });
} catch (error) {
  // 使用备用方案
  console.warn('模块加载失败，使用备用方案');
}
```

## 🔍 故障排除

### 常见问题

#### 问题1: 模块找不到

**症状**: `Error: Module xxx not found`

**解决方案**:
```bash
# 检查模块是否已注册
bun run modules:analyze

# 在ModuleDefinitions.ts中添加模块定义
```

#### 问题2: 循环依赖

**症状**: `Error: Circular dependency detected`

**解决方案**:
```bash
# 分析依赖关系
bun run modules:validate

# 重构模块设计，提取公共功能
```

#### 问题3: 初始化失败

**症状**: 模块初始化过程中出现错误

**解决方案**:
```typescript
// 检查初始化状态
const states = moduleInitializer.getAllModuleStates();

// 查看错误详情
for (const [moduleId, state] of Object.entries(states)) {
  if (state.status === 'error') {
    console.error(`${moduleId}初始化失败:`, state.error);
  }
}
```

## 🚀 进阶用法

### 1. 自定义模块分类

如果需要新的模块分类，可以扩展 `ModuleCategory`：

```typescript
// 在自定义类型文件中
export enum CustomModuleCategory {
  CUSTOM = 'custom',
  INTEGRATION = 'integration'
}

// 合并到现有分类
import { ModuleCategory } from './modules';

export const ExtendedModuleCategory = {
  ...ModuleCategory,
  ...CustomModuleCategory
};
```

### 2. 模块热重载

```typescript
// 开发环境下的热重载支持
if (process.env.NODE_ENV === 'development') {
  // 监听文件变化
  fs.watch('./src/modules', () => {
    console.log('模块文件变化，重新初始化...');
    
    // 销毁现有模块
    await destroyModules();
    
    // 重新初始化
    await initializeModules();
  });
}
```

### 3. 模块性能监控

```typescript
import { moduleInitializer } from './modules';

// 监控模块初始化性能
const startTime = Date.now();
await initializeModules();
const duration = Date.now() - startTime;

console.log(`模块初始化耗时: ${duration}ms`);

// 获取详细性能数据
const states = moduleInitializer.getAllModuleStates();
for (const [moduleId, state] of Object.entries(states)) {
  if (state.startTime && state.endTime) {
    console.log(`${moduleId}: ${state.endTime - state.startTime}ms`);
  }
}
```
