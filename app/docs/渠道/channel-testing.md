# 渠道测试

## 概述

渠道测试工具用于验证渠道配置和功能是否正常。

## 测试命令

```bash
# 测试所有渠道
/channel test

# 测试特定渠道
/channel test discord

# 查看渠道状态
/channel status
```

## 测试项目

| 测试项 | 说明 |
|--------|------|
| 连接测试 | 验证与消息服务的连接 |
| 鉴权测试 | 验证 Token 和凭据 |
| 消息发送 | 发送测试消息 |
| 消息接收 | 接收消息的能力 |
| 媒体支持 | 图片和文件处理 |

## 诊断输出

渠道测试会输出详细的诊断信息，包括：

- 连接延迟
- 认证状态
- 消息收发成功率
- 错误信息
- 建议修复方案
