# 用户知识库

欢迎使用你的个人知识库！在这里你可以保存和管理个人笔记、代码片段、学习资料等内容。

## 目录

- [快速开始](#快速开始)
- [使用指南](#使用指南)
- [示例文档](#示例文档)

## 快速开始

使用 `/knowledge` 命令管理你的知识库：

```
/knowledge list          - 列出所有知识文档
/knowledge create <标题>  - 创建新文档
/knowledge edit <标题>    - 编辑文档
/knowledge delete <标题>  - 删除文档
/knowledge search <关键词> - 搜索知识文档
```

## 使用指南

### 创建文档

```
/knowledge create 我的学习笔记
```

### 分类组织

你可以通过在知识库目录下创建子文件夹来组织你的文档：

```
知识库/
├── 开发笔记/
│   └── TypeScript 高级技巧.md
├── 学习心得/
│   └── 代码优化经验.md
└── 快速参考/
    └── 常用命令速查.md
```

### 搜索文档

```
/knowledge search 优化
```
