# 定时任务

## 概述

PY_APP 支持基于 Cron 表达式的定时任务，可以定期执行自动化操作。定时任务基于 `CronScheduler` 实现，支持 SQLite 持久化、投递重试和生命周期管理。

## 配置方法

### 通过命令

```bash
# 注册定时任务
/cron schedule "每日备份" "0 2 * * *" "backup"

# 查看所有定时任务
/cron list

# 停止定时任务
/cron stop <job-id>

# 手动触发定时任务
/cron trigger <job-id>

# 取消订阅/暂停
/cron unsubscribe

# 查看帮助
/cron help
```

### 通过配置文件

```json
{
  "cron": {
    "jobs": [
      {
        "name": "每日备份",
        "schedule": "0 0 2 * * *",
        "command": "backup",
        "enabled": true
      }
    ]
  }
}
```

## 任务状态

```
scheduled → running → completed
                │
                ├──→ failed
                └──→ paused → scheduled
```

| 状态 | 说明 |
|------|------|
| `scheduled` | 等待执行 |
| `running` | 执行中 |
| `completed` | 执行成功 |
| `failed` | 执行失败 |
| `paused` | 已暂停 |

## Cron 表达式参考

```
┌───────── 秒 (0-59)
│ ┌──────── 分钟 (0-59)
│ │ ┌─────── 小时 (0-23)
│ │ │ ┌────── 日期 (1-31)
│ │ │ │ ┌───── 月份 (1-12)
│ │ │ │ │ ┌──── 星期 (0-7, 0=周日)
│ │ │ │ │ │
* * * * * *
```

## 常见表达式

| 表达式 | 说明 |
|--------|------|
| `* * * * * *` | 每秒执行 |
| `0 * * * * *` | 每分钟执行 |
| `0 0 * * * *` | 每小时执行 |
| `0 0 2 * * *` | 每天凌晨2点 |
| `0 0 9 * * 1-5` | 工作日早9点 |
| `*/5 * * * * *` | 每5秒 |
| `0 0 1 * * 0` | 每周日凌晨1点 |
