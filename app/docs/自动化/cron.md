# 定时任务

## 概述

PY_APP 支持基于 Cron 表达式的定时任务，可以定期执行自动化操作。

## 配置方法

### 通过命令

```bash
# 注册定时任务
/cron add "每日备份" "0 0 2 * * *" "backup"

# 查看所有定时任务
/cron list

# 删除定时任务
/cron remove "每日备份"
```

### 通过配置文件

```json
{
  "cron": {
    "jobs": [
      {
        "name": "每日备份",
        "schedule": "0 0 2 * * *",
        "command": "backup",
        "enabled": true
      },
      {
        "name": "每周清理",
        "schedule": "0 0 3 * * 0",
        "command": "cleanup",
        "enabled": true
      }
    ]
  }
}
```

## Cron 表达式参考

```
┌───────── 分钟 (0-59)
│ ┌──────── 小时 (0-23)
│ │ ┌─────── 日期 (1-31)
│ │ │ ┌────── 月份 (1-12)
│ │ │ │ ┌───── 星期 (0-7, 0=周日)
│ │ │ │ │
* * * * *
```

## 常见表达式

| 表达式 | 说明 |
|--------|------|
| `0 0 * * *` | 每小时执行 |
| `0 0 2 * * *` | 每天凌晨2点 |
| `0 0 9 * * 1-5` | 工作日早9点 |
| `*/5 * * * *` | 每5分钟 |
| `0 0 1 * * 0` | 每周日凌晨1点 |
