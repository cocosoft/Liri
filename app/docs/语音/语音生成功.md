# 语音生成功

## 概述

Liri 语音子系统提供完整的语音生成与识别能力，涵盖文本转语音（TTS）、实时语音会话、语音唤醒、以及通道语音消息集成。

## 架构

```
用户输入
  ├── 文本输入 → TTS 合成 → 音频输出
  ├── 语音输入 → STT 识别 → 文本 → AI 处理 → TTS 输出
  ├── WebSocket 实时语音会话 → Gemini Live / OpenAI Realtime
  └── 通道语音消息（Telegram / Discord）→ 附件管理
```

## 模块结构

| 模块 | 路径 | 说明 |
|------|------|------|
| voice/ | `src/voice/` | 实时语音子系统（WebSocket 会话、事件总线、音频管线） |
| services/voice/ | `src/services/voice/` | 服务层（TTS、STT、录音） |
| VoiceToolBridge | `src/voice/VoiceToolBridge.ts` | 实时会话的工具桥接 |
| VoiceGatewayBridge | `src/voice/VoiceGatewayBridge.ts` | HTTP→WebSocket 升级网关 |

## TTS 提供商

| 提供商 | 类型 | 说明 |
|--------|------|------|
| EdgeTTS | HTTP | 微软 Edge 浏览器内置 TTS（免费） |
| OpenAI TTS | HTTP | OpenAI TTS API（需 API Key） |
| Command TTS | 本地 | 系统命令 TTS（PowerShell/SAPI/say/espeak） |

## 实时语音会话

支持通过 WebSocket 建立实时语音会话：

- **端点**: `ws://host/voice`
- **协议**: WebSocket (RFC 6455)，自定义帧格式
- **适配器**: Gemini Live API、OpenAI Realtime API


## 通道集成

### Telegram 语音消息

- 自动检测 `voice` 字段
- 通过 `getFile` API 下载语音文件
- 保存到附件系统 (`data/attachments/`)
- 以 `messageType: 'voice'` 的 `MessageContext` 分发

### Discord 语音频道

- 支持 `GUILD_VOICE_STATES` intent
- 追踪 `VOICE_STATE_UPDATE` 和 `VOICE_SERVER_UPDATE` 事件
- 提供 `joinVoiceChannel()` / `leaveVoiceChannel()` 方法
- 通过 op 4 `VOICE_STATE_UPDATE` 加入/离开频道

## 命令

| 命令 | 说明 |
|------|------|
| `/voice` | 切换语音模式（enable/disable/status） |
| `/voice enable` | 启用语音输入模式 |
| `/voice disable` | 禁用语音输入模式 |
| `/voice status` | 查看语音模式状态和录音工具 |
