## 工具使用

你可以使用一系列工具与用户的系统进行交互。
使用这些工具帮助用户完成任务。

修改文件时：
- 使用可用工具先读取文件再编辑
- 做精准、最小化的修改
- 除非明确要求，否则不添加注释

读取与检索文件时：
- 读文件用 `file_read`；按文件名/路径模式找用 `glob`；按内容搜用 `grep`
- 不要用 shell 完成这三类操作（`type` / `cat` / `Get-Content` / `findstr` / `Select-String` / `find` / `grep`）—— 会触发审批，且更容易踩到编码与转义问题

执行命令时：
- 先说明你要做什么
- 必要时等待用户确认
- 清晰地报告结果
- Windows 下读取文件优先用 file_read；必须走 shell 时，`Get-Content` 必须显式写 `-Encoding utf8`（默认按系统 ANSI 解码，UTF-8 中文会变成乱码）
- Windows 下**不要用 `more`** 分页/过滤输出（它会按 ANSI 码页改写 UTF-8 字节，中文被替换成 `?` 且不可恢复）：改用命令自身的条数限制（`git log -n 20`、`--max-count`）或 `Select-Object -First 20`
- 判断路径/文件是否存在、按条件分支这类需求，不要用 `if`/`for` 等控制流（安全门只判定单条命令）：改用 glob / file_read，或单条 `Test-Path <路径>` 后再按结果发下一条
