# 快速上手

> 从零搭建 PY_APP 开发环境，5 分钟跑起来。

---

## 环境要求

- **Bun** ≥ 1.1 (JavaScript 运行时，用于 TypeScript 直接执行)
- **Node.js** ≥ 22 (可选，Bun 兼容)
- **Git** (版本管理)

## 安装

```bash
git clone https://github.com/cocosoft/PY_APP.git
cd PY_APP/backend
bun install
```

## 配置

```bash
# 创建配置文件目录
mkdir -p ~/.pyapp

# 设置 API 密钥（至少一个）
export ANTHROPIC_API_KEY="sk-ant-..."

# 可选：其他提供商
export OPENAI_API_KEY="sk-..."
export DEEPSEEK_API_KEY="sk-..."
```

## 运行

```bash
# 交互式 REPL 模式
bun start

# 或开发模式（热重载）
bun run dev
```

## 常用脚本

| 命令 | 说明 |
|------|------|
| `bun start` | 启动 REPL |
| `bun run dev` | 开发模式（文件变更自动重启） |
| `bun run typecheck` | TypeScript 类型检查 |
| `bun test` | 运行全部测试 |
| `bun run lint:fix` | ESLint 自动修复 |

## 项目结构约定

- **扩展名**: 所有 TypeScript 源文件使用 `.ts`
- **Barrel 导出**: 每个模块目录有 `index.ts` 统一导出
- **测试文件**: 放在 `__tests__/` 子目录下，以 `.test.ts` 结尾
- **导入别名**: `@modules/` 映射到 `src/` 根

## 代码风格

遵循项目已有的 TypeScript 风格：
- 使用 JSDoc 注释在类和函数上
- 不使用行内注释（除非必要）
- 文件间保留适当空行
- 遵循 `prettier` + `eslint` 规则

## 第一个 PR：添加一个新命令

```bash
# 1. 创建命令文件
# src/commands/builtin/hello/index.ts

# 2. 注册到 barrel 导出
# 修改 src/commands/builtin/index.ts

# 3. 验证
bun run typecheck
bun run lint:fix
bun test

# 4. 启动测试
bun start
# 输入 /hello
```
