# 添加新的 AI 提供商

> 如何让 PY_APP 支持新的 AI 模型提供商。

---

## 接口契约

所有提供商实现 [AIProvider](../../src/ai/providers/AIProvider.ts) 接口：

```typescript
export interface AIProvider {
  readonly id: string;          // 唯一标识 (e.g. 'custom-provider')
  readonly displayName: string; // 显示名称 (e.g. 'My Custom Provider')

  chat(messages: ChatMessage[], options?: ChatOptions): Promise<ChatResponse>;
  chatStream(messages: ChatMessage[], options?: ChatOptions): AsyncGenerator<string, ChatResponse, unknown>;
  listModels(): Promise<string[]>;
  validateConfig(config: ProviderConfig): ProviderValidationResult;

  setToolRegistry?(registry: unknown): void;
  setToolExecutor?(executor: unknown): void;
  supportsThinking?(model: string): boolean;
}
```

---

## 步骤一：创建 Provider 文件

在 `src/ai/providers/` 下新建文件，例如 `MyProvider.ts`：

```typescript
import type { AIProvider, ProviderConfig, ChatOptions } from './AIProvider';
import type { ChatMessage, ChatResponse } from '../models/types';

export class MyProvider implements AIProvider {
  readonly id = 'my-provider';
  readonly displayName = 'My Custom Provider';

  private apiKey: string;

  constructor(config: ProviderConfig) {
    this.apiKey = (config.apiKey as string) || process.env.MY_API_KEY || '';
  }

  async chat(messages: ChatMessage[], options?: ChatOptions): Promise<ChatResponse> {
    const response = await fetch('https://api.my-provider.com/v1/chat', {
      method: 'POST',
      headers: { 'Authorization': `Bearer ${this.apiKey}` },
      body: JSON.stringify({ model: options?.model, messages }),
    });
    const data = await response.json();
    return {
      content: data.choices[0].message.content,
      stop_reason: 'stop',
      usage: {
        prompt_tokens: data.usage?.prompt_tokens || 0,
        completion_tokens: data.usage?.completion_tokens || 0,
        total_tokens: data.usage?.total_tokens || 0,
      },
    };
  }

  async *chatStream(messages: ChatMessage[], options?: ChatOptions): AsyncGenerator<string, ChatResponse, unknown> {
    const response = await fetch('https://api.my-provider.com/v1/chat', {
      method: 'POST',
      headers: { 'Authorization': `Bearer ${this.apiKey}` },
      body: JSON.stringify({ model: options?.model, messages, stream: true }),
    });
    // 处理 SSE 流式响应
    let fullContent = '';
    for await (const chunk of parseSSE(response.body!)) {
      fullContent += chunk;
      yield chunk;
    }
    return {
      content: fullContent,
      stop_reason: 'stop',
      usage: { prompt_tokens: 0, completion_tokens: 0, total_tokens: 0 },
    };
  }

  async listModels(): Promise<string[]> {
    return ['my-model-1', 'my-model-2'];
  }

  validateConfig(config: ProviderConfig): { valid: boolean; errors: string[]; warnings: string[] } {
    const errors: string[] = [];
    if (!config.apiKey && !process.env.MY_API_KEY) {
      errors.push('API key required');
    }
    return { valid: errors.length === 0, errors, warnings: [] };
  }
}
```

## 步骤二：注册到 Barrel 导出

修改 `src/ai/providers/index.ts`：

```typescript
export { MyProvider } from './MyProvider';
```

## 步骤三：注册到 AIModelManager（可选）

如果需要在启动时自动注册：

```typescript
// 在 src/ai/AIModelManager.ts 或 init.ts 中
providerRegistry.register('my-provider', new MyProvider(config));
```

## 可选增强

| 能力 | 如何添加 |
|------|----------|
| **思考配置** | 实现 `supportsThinking(model)` 返回 `true` |
| **工具调用** | 在 `chat()`/`chatStream()` 中处理 `options.tools` |
| **提示缓存** | 在消息中添加 `cache_control: { type: "ephemeral" }` 断点 |
| **模型回退** | 用 `createFallbackProvider()` 包装 `chat`/`chatStream` |
| **成本跟踪** | 在 `CostTracker` 中注册模型定价 |
