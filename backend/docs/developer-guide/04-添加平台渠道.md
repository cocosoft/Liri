# 添加新的消息平台渠道

> 如何让 PY_APP 接入新的消息平台（如 Telegram/Discord/Slack/企业微信等）。

---

## 接口契约

所有渠道适配器实现 [ChannelInterface](../../src/channels/registry/ChannelRegistry.ts) 接口：

```typescript
export interface ChannelInterface {
  name: string;
  type: string;
  enabled: boolean;
  connected: boolean;

  connect(): Promise<boolean>;
  disconnect(): Promise<void>;
  sendMessage(target: string, text: string): Promise<boolean>;
  getStatus(): Record<string, unknown>;

  homeChannelId?: string;
  supportsThreads?: boolean;
  sendThreadMessage?(target: string, threadId: string, text: string): Promise<boolean>;
}
```

---

## 步骤一：创建适配器文件

在 `src/channels/platforms/` 下新建，例如 `NewPlatformChannel.ts`：

```typescript
import { ChannelStatus } from '../../core/gateway/types';

export class NewPlatformChannel {
  readonly name: string;
  readonly type = 'newplatform';
  readonly enabled = true;
  readonly homeChannelId: string = '';

  private _status: ChannelStatus = ChannelStatus.IDLE;
  private _connected = false;

  constructor(config: { name: string; token: string }) {
    this.name = config.name;
  }

  get connected(): boolean { return this._connected; }

  async connect(): Promise<boolean> {
    // 建立连接（WebSocket/HTTP 轮询等）
    this._connected = true;
    this._status = ChannelStatus.CONNECTED;
    return true;
  }

  async disconnect(): Promise<void> {
    this._connected = false;
    this._status = ChannelStatus.DISCONNECTED;
  }

  async sendMessage(target: string, text: string): Promise<boolean> {
    // 发送消息到平台 API
    return true;
  }

  getStatus(): Record<string, unknown> {
    return { status: this._status, connected: this._connected };
  }
}
```

---

## 步骤二：注册到 Barrel 导出

修改 `src/channels/platforms/index.ts`：

```typescript
export { NewPlatformChannel } from './NewPlatformChannel';
```

---

## 步骤三：扩展 ChannelId/PlatformType

在 ChannelId 和 PlatformType 枚举中添加新平台标识：

```typescript
// 在 channels/ 相关类型定义中
export type ChannelId = 'irc' | 'slack' | 'line' | 'nostr' | ... | 'newplatform';
```

## Home Channel 与线程支持

如果平台支持默认通道和线程消息：

```typescript
homeChannelId = 'chat_12345';
supportsThreads = true;

sendThreadMessage(target: string, threadId: string, text: string): Promise<boolean> {
  // 在指定线程中回复
}
```

至此 `ChannelRegistry.sendToHomeChannel()` / `sendThreadReply()` 自动生效。
