## 一、添加新工具

### 继承 BaseTool

```typescript
import { BaseTool } from '../../tools/BaseTool';
import type { ToolParam, ToolUseContext, ToolResult } from '../../tools/types';

export class MyTool extends BaseTool<string, string, never> {
  name = 'my-tool';
  description = 'My custom tool description';
  params: ToolParam[] = [
    { name: 'input', type: 'string', description: 'Task input', required: true },
  ];

  async execute(input: string, context: ToolUseContext): Promise<ToolResult<string>> {
    // 核心逻辑
    return { success: true, result: `Processed: ${input}` };
  }

  // 可选重写
  isReadOnly(): boolean { return true; }
  isDestructive(): boolean { return false; }
  isConcurrencySafe(): boolean { return false; }
}
```

### 注册工具

在 `src/tools/` 的 barrel 导出或 `ToolManager` 中注册：

```typescript
toolManager.registerTool(new MyTool());
```

### 参考实现

- 文件读取 → [FileReadTool](../../src/tools/FileReadTool/FileReadTool.ts)

## 二、添加新命令

### Command 接口

```typescript
export interface Command {
  type: CommandType;       // 'prompt' | 'action' | 'tool' | 'chat' | 'local'
  name: string;            // 命令名
  description: string;     // 描述
  aliases?: string[];      // 别名
  argumentHint?: string;   // 参数提示
  loadedFrom: string;      // 来源标记 ('builtin'/'user'/'plugin')

  // prompt 类型
  getPromptForCommand?(args: string): Promise<Array<{ type: 'text'; text: string }>>;

  // action 类型
  call?(args: string): Promise<string>;
  execute?(args: string, context: CommandContext): Promise<CommandResult>;
}
```

### 示例：提示类命令

```typescript
const myCommand: Command = {
  type: 'prompt',
  name: 'mycmd',
  description: 'My custom command',
  loadedFrom: 'builtin',
  async getPromptForCommand(args: string) {
    return [{ type: 'text', text: `Process this: ${args}` }];
  },
};
```

### 注册命令

修改 `src/commands/builtin/index.ts`，添加导出。

- advisor 命令 → [advisor.ts](../../src/commands/advisor.ts)

## 三、添加新技能

### 技能结构

技能是 YAML front matter + Markdown 正文的系统提示文件：

```markdown
---
name: my-skill
description: My custom skill
platform: all
user-invocable: true
---

# My Skill

Instructions for the agent...
```

### 技能目录

- 内置技能放在 `src/skills/builtin/`
- 用户技能放在 `~/.py_app/skills/`

### 技能条件匹配

YAML front matter 支持条件过滤：

```yaml
---
platform: telegram        # 限制平台
os: linux                 # 操作系统
require_env: MY_API_KEY   # 需要环境变量
---
```

系统通过 [SkillConditionMatcher.ts](../../src/skills/SkillConditionMatcher.ts) 自动匹配。

### 技能生命周期

[SkillCurator.ts](../../src/skills/SkillCurator.ts) 自动管理：
- **pin**: 固定重要技能
- **archive**: 归档长期未使用的技能
- **consolidate**: 合并重复技能
- **patch**: 更新技能内容

策展器默认每 7 天自动运行一次。
