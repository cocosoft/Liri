## 技术栈

- **TypeScript** — 全栈语言
- **Bun** — JavaScript 运行时（直接执行 `.ts` 文件）
- **OpenTelemetry** — 监控遥测标准
- **Rust** — 高性能安全分析（通过 FFI 调用）
