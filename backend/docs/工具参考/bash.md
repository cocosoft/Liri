# Bash - 命令执行工具

## 描述

在系统中执行 Bash 命令，支持命令执行和输出捕获。

## 输入参数

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `command` | string | 是 | 要执行的命令 |
| `description` | string | 否 | 命令说明 |

## 使用示例

```javascript
// 执行简单命令
Bash({ command: "dir" })

// 执行带管道的命令
Bash({ command: "type package.json | findstr version" })

// 执行脚本
Bash({ command: "node -e \"console.log('Hello')\"" })
```

## 安全限制

### 只读验证

- 写操作命令需要额外确认
- 危险命令（rm、del、format 等）可能被阻止

### 路径验证

- 只能操作允许的目录
- 禁止操作系统关键路径

### 模式验证

- 禁止使用通配符删除
- 禁止链式执行危险操作

## 返回值

返回命令的标准输出和标准错误内容。

## 注意事项

- 命令超时时间默认为 30 秒
- 长时间运行的任务建议使用任务系统
- 敏感信息（密码、令牌等）不会记录到日志
