# Diffs - 差异比较工具

## 描述

Diffs 工具用于比较文件或文本内容的差异。

## 输入参数

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `old` | string | 是 | 原始内容 |
| `new` | string | 是 | 新内容 |

## 使用示例

```javascript
// 比较两个版本
Diffs({
  old: "Hello World",
  new: "Hello PY_APP"
})
```

## 返回值

返回统一的差异格式，包含添加、删除和修改的标记。

## 特点

- 支持行级别和字符级别的比较
- 输出格式兼容标准 diff 工具
- 适合在终端中查看差异
