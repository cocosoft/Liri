# 获取帮助

## 问题反馈

### GitHub Issues

在 GitHub 仓库提交 Issue：

- Bug 报告: 使用 Bug Report 模板
- 功能请求: 使用 Feature Request 模板
- 问题咨询: 使用 Question 模板

### 提交 Issue 指南

提交 Issue 时请提供：

1. **环境信息**: 操作系统、运行时、版本
2. **问题描述**: 清晰描述问题现象
3. **复现步骤**: 最小化的复现步骤
4. **预期行为**: 你认为应该发生什么
5. **实际行为**: 实际发生了什么
6. **日志信息**: 相关的错误日志

## 诊断信息

在提交问题前，运行以下命令收集诊断信息：

```bash
# 查看版本信息
/status

# 收集系统诊断
/system-diagnose

# 导出日志
/logs export
```

## 功能请求

如果你有新功能建议，请提供：

- 功能描述
- 使用场景
- 期望的行为
- 可能的实现方案

## 社区支持

- 查看文档中心获取详细文档
- 搜索已有 Issue 寻找解决方案
- 在已有 Issue 下参与讨论
