# 快速开始

本文档帮助您在 5 分钟内上手 PY_APP。

## 启动应用

```bash
cd backend
bun run dev
```

## 基本交互

启动后进入交互式 REPL 模式，您可以直接输入问题或使用命令。

### 常用命令

| 命令 | 说明 |
|------|------|
| `/help` | 查看所有可用命令 |
| `/skill list` | 查看技能列表 |
| `/task list` | 查看任务列表 |
| `/config show` | 查看当前配置 |
| `exit` | 退出应用 |

### 提问示例

```
你好，请解释什么是依赖注入？
```

```
请帮我读取 src/index.ts 文件的内容
```

## 使用工具

PY_APP 提供丰富的工具集：

```bash
# 读取文件
请读取 config.json 的内容

# 搜索信息
请搜索 TypeScript 装饰器教程

# 生成图片
请生成一张猫的图片

# 执行代码
请帮我执行这段 Python 代码: print("Hello")
```
