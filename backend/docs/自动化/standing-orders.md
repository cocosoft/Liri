# 常设指令

## 概述

常设指令（Standing Orders）是持续有效的规则和约束，Agent 在所有对话中都会遵守。

## 配置方法

```bash
# 添加常设指令
/order add "在所有回复中使用中文"

# 查看常设指令
/order list

# 删除常设指令
/order remove "在所有回复中使用中文"

# 清空常设指令
/order clear
```

## 常设指令示例

```
始终使用中文回复
在提供代码时包含类型定义
重要操作前先询问用户确认
记录所有文件修改到日志
优先使用现有的工具而非创建新文件
```

## 作用范围

- 常设指令对所有对话生效
- 与系统提示词（system prompt）一起注入到 Agent
- 贯穿整个会话生命周期

## 与普通指令的区别

| 特性 | 常设指令 | 会话指令 |
|------|---------|---------|
| 范围 | 全局 | 当前会话 |
| 持久性 | 持久保存 | 会话结束后失效 |
| 优先级 | 高 | 低 |
