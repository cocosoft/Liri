# 聊天界面优化方案（v2 — 经 Liri Review）

基于对 Grok、Microsoft Copilot 竞品分析及当前 Liri 前端代码审查（参见 `logs/app.md`）。
本次修订纳入 Liri 的 9 条 review 意见。

---

## 一、现状对比

| 维度 | Grok | Copilot | Liri 当前 |
|:---|:---:|:---:|:---:|
| 消息日期分组 | 日期分隔线 | 对话标题 | 无 |
| 用户消息渲染 | Markdown | Markdown | 纯文本 `whitespace-pre` |
| 操作按钮 | 常驻图标 | 常驻文字 | hover 触发 |
| Token/成本 | 不显示 | 不显示 | 每条消息显示 |
| "回到底部" | 有 | 有 | 无 |
| 流式光标 | 脉冲波纹 | 无 | 简单闪烁 `|` |
| 头像 | 品牌标识+首字母 | 品牌标识 | emoji+图片，无 fallback |
| 轮次导航 | 无 | 无 | 有（`RoundNavigator`，独特优势） |

## 二、实施计划

### 阶段 1：核心技术体验（高优先级）

#### 1.1 消息列表日期分组 + "回到底部"按钮

**目标文件**：`ChatMessageList.tsx`、`ChatArea.tsx`

**Liri review 意见**：
- 当前 `ChatArea.tsx` 已有滚动按钮样式 `absolute bottom-16 right-6 z-10`，应**复用并改造**而非重写。
- `App.tsx` 中有 `MobileBottomNav` 固定底部，按钮定位需避免与它重叠。
- `SessionHeader.tsx` 已显示轮次计数和会话标题，日期分隔线需与它协调不冲突。

**改动**：
- 改造 `ChatArea.tsx` 中已有的滚动按钮：改为检测 `isUserScrolledUp` 后渐显/渐隐，维持 `absolute bottom-16 right-6 z-10`
- 移动端：按钮上移为 `bottom-20`，避开 `MobileBottomNav`
- 日期分隔线：仅在跨日期同一条消息前插入，不影响 `SessionHeader` 的轮次标题
- `useAutoScroll.ts` 增加 `isUserScrolledUp` 状态

```
[日期分隔组件]
{shouldShowDateSeparator(i) && (
  <div className="flex items-center justify-center py-2">
    <span className="rounded-full bg-gray-200 px-3 py-0.5 text-xs text-gray-400 dark:bg-gray-700">
      {formatDateLabel(msg.createdAt)}  <!-- 今天 / 昨天 / 2026-07-10 -->
    </span>
  </div>
)}

[回到底部 — 改造 ChatArea.tsx 已有按钮]
{isUserScrolledUp && (
  <button onClick={scrollToBottom}
    className="absolute bottom-16 right-6 z-10 rounded-full bg-blue-500 p-2 shadow-lg
               md:bottom-16 max-md:bottom-20"  <!-- 移动端避开 MobileBottomNav -->
  >
    ↓
  </button>
)}
```

#### 1.2 用户消息 Markdown 渲染 + 左右交替布局

**目标文件**：`ChatMessage.tsx`

**Liri review 意见**：当前代码用户气泡已用 `ml-auto`，但缺少 `flex` 容器包裹来彻底实现左右分离。

**改动**：
- 外层加 `flex` 容器 + `justify-end`（用户）/ `justify-start`（AI）包裹
- 用户消息 `content` 走轻量 Markdown 渲染（代码块、内联代码、链接），复用现有 `BlockRenderer`
- 用户气泡增加 `shadow-sm` 立体感
- 保留 `max-w-[80%]` 宽度限制

```
<div className={`flex w-full ${isUser ? 'justify-end' : 'justify-start'} items-start gap-3`}>
  {!isUser && <Avatar />}
  <div className={`max-w-[80%] ${isUser ? 'rounded-2xl bg-gradient-to-r from-blue-500 to-blue-600 px-4 py-2 text-white shadow-sm' : 'rounded-2xl bg-gray-50 px-4 py-2 dark:bg-gray-800'}`}>
    <MarkdownRenderer content={msg.content} />
  </div>
  {isUser && <Avatar />}
</div>
```

#### 1.3 操作按钮常驻显示

**目标文件**：`ChatMessage.tsx`

**Liri review 意见**：
- 用户消息的操作按钮（编辑/分支）当前也是 hover 触发，需一并考虑。
- "重新生成" vs "续写"是两个不同功能，不能混淆放在同位置。
- 流式输出中点击"重新生成"需要 `isStreaming` 守卫。

**改动**：
- AI 消息底部：**复制** + **重新生成**常驻（不依赖 hover）；**续写**单独保留；次要操作入 `⋯` 菜单
- 用户消息底部：**编辑**常驻；**分支**入 `⋯` 菜单
- 重新生成按钮：`isStreaming` 时 disabled + 灰色 + `⏳` 动画
- 复制操作增加 toast "已复制"

```
[AI 消息底部操作栏]
<div className="mt-1 flex gap-2 text-xs text-gray-400">
  <button onClick={handleCopy} className="hover:text-gray-600">📋 复制</button>
  <button onClick={handleRegenerate} disabled={isStreaming}
    className={`${isStreaming ? 'cursor-not-allowed text-gray-300' : 'hover:text-gray-600'}`}>
    {isStreaming ? '⏳' : '🔄'} 重新生成
  </button>
  <button onClick={handleContinue} className="hover:text-gray-600">✏️ 续写</button>
  <MenuButton items={[保存, 调试信息]} />
</div>

[用户消息底部操作栏]
<div className="mt-1 flex gap-2 text-xs text-gray-400">
  <button onClick={handleEdit} className="hover:text-gray-600">✏️ 编辑</button>
  <MenuButton items={[分支, 删除]} />
</div>
```

### 阶段 2：信息组织与视觉（中优先级）

#### 2.1 Token/成本信息折叠

**目标文件**：`ChatMessage.tsx`

**改动**：
- Token 和成本信息 **默认隐藏**，仅在点击消息旁的 `📊` 图标时展开
- Cache 信息（CR/CW）仅 `VITE_SHOW_DEBUG=true` 时显示
- 可选：在会话顶部栏显示本轮对话累计 token

#### 2.2 时间戳移到气泡右上角

**目标文件**：`ChatMessage.tsx`

**改动**：
- 时间戳移到消息气泡右上角（Grok 风格），灰色小字
- 移除底部 `border-t` 分隔线，减少视觉噪音

#### 2.3 头像优化

**目标文件**：`ChatMessage.tsx`

**改动**：
- 用户头像显示**用户名首字母**（如 cocosoft → C），加随机背景色 `hsl(nameHash, 70%, 60%)`
- `<img>` 加 `onError` fallback，防止裂图
- AI 头像 38px > 用户头像 32px，区分主辅地位

```
{isUser ? (
  <div className="flex h-8 w-8 items-center justify-center rounded-full text-sm text-white"
       style={{ background: userColor }}>
    {userInitial}
  </div>
) : (
  <img src={liriLogo} className="h-9 w-9 rounded-full" onError={imgFallback} />
)}
```

### 阶段 3：交互增强（低优先级）

#### 3.1 流式光标脉冲动画

**目标文件**：`ChatMessage.tsx` + `markdown-theme.css`

**改动**：
- 简单闪烁 `|` 替换为 3 个脉冲圆点 `● ● ●`，依次淡入淡出
- CSS animation: `pulse-dot` 0.6s ease-in-out infinite alternate

#### 3.2 分支交互简化

**目标文件**：`ChatMessage.tsx`

**改动**：
- AI 消息上移除分支按钮（已在 1.3 中处理）
- 仅在用户消息的 `⋯` 菜单中保留分支入口
- 编辑并重新发送用户消息时自动创建分支

#### 3.3 调试信息开关

**目标文件**：`AssistantMessage.tsx`

**改动**：
- `DebugBlockInfo` 显示条件：`NODE_ENV === 'development' || VITE_SHOW_DEBUG === 'true'`
- explicit 环境变量控制，方便 staging 排查

#### 3.4 移动端长按操作菜单

**改动**：
- 移动端消息卡片增加 `onContextMenu` / 长按弹出操作菜单
- 包含：复制、回复、重新生成、保存
- 注意不与 `MobileBottomNav` 重叠

## 三、Liri 独特功能保留

| 功能 | 当前状态 | 方案态度 |
|:---|------|:---|
| **RoundNavigator**（轮次导航） | `ChatArea.tsx` 中已有 | **保留并优化**：在与日期分隔线共存时，RoundNavigator 定位到轮次级别，日期分隔线定位到天级别，互补不冲突 |
| **EmptyState**（欢迎页） | `ChatMessageList.tsx` 中已有 logo+欢迎语+快捷操作 | **保持一致性**：新打造的左右交替布局/头像/按钮样式应与 EmptyState 视觉风格统一 |
| **SessionHeader**（轮次计数+标题） | `SessionHeader.tsx` | **保留**：日期分隔线仅显示日期标签（今天/昨天/日期），不重复轮次信息 |
