# 对比维度框架 / Comparison Dimensions

> Phase 2 产物。用于 Phase 3 逐维对比。

---

## 维度体系

对标分析共 7 大维度、23 个子属性：

```
D1: 文档处理管线    (5 子属性)
D2: 存储与索引      (5 子属性)
D3: 检索与搜索      (4 子属性)
D4: 知识类型        (3 子属性)
D5: AI 集成         (3 子属性)
D6: 可扩展性与生态   (3 子属性)
D7: 系统稳定与运维   (3 子属性)
```

---

## 完整度等级定义

| 等级 | 标记 | 定义 |
|------|:----:|------|
| 不存在 | ❌ | 源码中没有任何此功能的实现 |
| 基础 | ⚠️ | 有接口/抽象但实现不完整，或实现但缺少关键特性 |
| 完整 | ✅ | 功能实现完整，有测试覆盖 |
| 领先 | ★ | 功能完整且有独特创新，竞品明显不及 |

## D1: 文档处理管线

| 子属性 | 说明 | 关键考察点 |
|--------|------|----------|
| D1.1 文件格式支持 | 支持解析的文档格式种类 | PDF、DOCX、EPUB、PPTX、Excel、Markdown、HTML、图片等 |
| D1.2 文档解析架构 | 解析器的技术实现方式 | 单进程/微服务、同步/异步、可扩展性 |
| D1.3 分块策略 | 文本分块的智能化程度 | 固定大小/递归/标题感知/自适应策略 |
| D1.4 摄取自动化 | 文件自动发现与处理 | 目录监控、定时扫描、手动触发 |
| D1.5 文档编译 | LLM 驱动的结构化转换 | 原始文件→结构化知识、Many-to-Many/Many-to-One |
